The problem is that a full eco-movement insert took about two and a half hours against prod, with almost none of that time spent doing database work. Each of the thirty-six thousand stations made about eleven sequential round trips to re-read refs and a station that the run already held in memory. At roughly twenty milliseconds of latency, that added up to about four hundred twenty-five thousand round trips spent waiting. Separately, the twenty-five percent deletion guard covered only the prune step, and a delete that failed still counted as a removal.

The change is that station refs, connector refs, and the existing stations are now each loaded once before the loop. As a result, an unchanged station now costs no queries. The run is bounded by the up-front load, plus writes for stations that actually changed. Knock-outs and prune now draw on one deletion budget for the entire run, and only deletions that actually succeed are counted. This means the end-of-run summary no longer reports removals that never happened. Also, the truck-charger C.S.V. had lost its header row earlier on this branch. That header has been restored. The seeder matches columns by name through the C.S.V. struct tags, so without the header, every charger would seed with no coordinates, operator, or connectors.

There are a few technical details worth noting. The up-front station load now passes the public principal, which is what carries reader access on the eco-movement price dataset. Without the public principal, a run under any principal other than the admin group sees no prices and rewrites every station. The change also widens the station access join, so knock-out and prune candidates can include stations that are readable only through the public group. This remains scoped to the target dataset, and every delete and upsert still checks write access using the run principal alone.

The functions Find Station I.D. By External I.D., Find Connector I.D. By External I.D., and Station I.D.s With External Ref have been removed. The fetcher was their only caller.
